Connect

Three ways in. Pick one; they all land on the same network. If you have never used Reticulum, the wiki walkthrough takes you from nothing to connected.

MeshChatX easiest

All-in-one client — messaging, files, voice, pages — and it manages its own Reticulum config. Windows, macOS, Linux, Android.

  1. Download and open it
  2. Interfaces → Add Interface → TCPClientInterface
  3. Host rns.scotmesh.net, port 4242, save, restart

The interface comes up within seconds; announces start arriving straight away.

Config file already running Reticulum

Add to the [interfaces] section of ~/.reticulum/config, then restart and run rnstatus.

  [[ScotMesh Backbone]]
    type = TCPClientInterface
    enabled = yes
    target_host = rns.scotmesh.net
    target_port = 4242

No account, no key exchange, nothing to approve — every link is end-to-end encrypted by default.

I2P behind CGNAT or a locked-down firewall

No port forwarding at either end. Needs a local I2P router with SAMv3 on — apt install i2pd is enough.

  [[ScotMesh I2P]]
    type = I2PInterface
    enabled = yes
    peers = a3pswrtvpuro62ijhb7lwdt2n6aqgajglof27ynbonynmolzlz7q.b32.i2p

Give it a few minutes on first start. I2P builds tunnels before the interface comes up, so it sits as Down for a while — normal, not a fault. Slower than TCP; use it when TCP is not an option. More on the wiki.

Radio

These are the LoRa settings the network uses. Every radio must match all five exactly — a board with a different spreading factor is not weakly connected, it is completely deaf, and nothing reports an error.

Frequency433.775 MHz869.4625 MHz

No ScotMesh radio is on air yet. The backbone is internet and I2P only today. These settings are published now so a radio built now will hear the others when they arrive.

Flash a radio or build a node in your browser

Chrome or Edge on a desktop, USB cable. The ScotMesh Flasher walks you through it: an RNode radio for a computer or phone (the app you connect it to sets the radio profile), or a standalone microReticulum node — a self-contained transport node for a solar box or hilltop, provisioned with the ScotMesh profile, a name and your management identity. Boards, Bluetooth pairing and the config-file form of these settings are on the RNode page.

Want to peer with us? Point a TCPClientInterface at rns.scotmesh.net:4242, or use the I2P address, then tell us on Discord or in the scotmesh room so we can peer back. Transport nodes relay only encrypted traffic and cannot read what passes through them — peering costs you a config line and nothing else. UK and Irish links especially welcome.
